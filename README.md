# University Management System

A full-stack application for managing university and student information, built with Spring Boot, PostgreSQL, and React (coming soon). This project includes CI/CD pipelines, Docker containerization, and AWS deployment.

## Tech Stack

### Backend
- Java 22
- Spring Boot 3.3.2
- PostgreSQL
- Maven

### DevOps
- Docker
- GitHub Actions
- AWS EC2
